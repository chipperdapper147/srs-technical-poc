# Label

The text label for a form control (`label` text style: 14px, medium).

**Source:** `apps/web/src/components/ui/label.tsx`.

## What the consumer provides

`htmlFor` matching the control's `id`, and the label text from the view model. Put the label above inputs, with `space-y-1.5` (6px) between them, and to the left of switches.
